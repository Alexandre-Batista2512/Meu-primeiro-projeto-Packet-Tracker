# Meu Primeiro Laboratório no Cisco Packet Tracer

Este é o meu primeiro projeto prático estudando redes de computadores! O objetivo foi criar uma rede local (LAN) simples para entender como os dispositivos se comunicam através de um switch.

## O que foi feito:
- Conexão física de 3 computadores (PCs) a um Switch Cisco 2960 usando cabos de cobre direto (Copper Straight-Through).
- Configuração manual de endereçamento IP estático (IPv4) e máscara de sub-rede em cada máquina.
- Teste prático de comunicação utilizando o comando `ping` no terminal.
